# Changelog

All notable changes to the CodexBar Plasma widget are documented in this file.

## Unreleased

### Features

- Add a **Reliability** section to General settings: retries per refresh, failure backoff cap (default 3 minutes), and background cost scan timeout
- Add a self-hosted sync server (`codexbar-plasmoid sync-server`): widgets publish their locally fetched usage snapshots, and the server merges them per (provider, account) with cross-device daily cost/history totals
- Publish locally fetched entries to the sync server after each refresh (best effort, failures never interrupt rendering) — filter them behind General → Sync server
- New provider source **Sync server**: a widget without provider credentials can render the merged cross-device data (never sends credentials anywhere; publishes exclude remote-sourced entries so server data cannot loop back)
- Add a **Sync all from the server** mode on the Providers page: every provider renders the server's merged cross-device state and the widget skips local fetching entirely (no CLI, no cost scan, no publish). The per-provider list grays out because sources, accounts, and enabled flags no longer apply

### Improvements

- Retry a provider call once when it failed early with a transient error (a busy Codex app-server socket, a 429, a reset connection), with jittered backoff
- Cap the failure backoff at 3 minutes by default instead of 10, so a provider that recovers is picked up within a couple of refreshes
- Spread automatic refreshes by ±15% so several widgets do not poll on the same boundary and invite provider rate limits
- Say "Limits unavailable — showing local spend" when a provider falls back to local cost, instead of showing an unexplained cost-only card

### Fixes

- Install the sync server binary where its systemd unit looks for it: `scripts/install-sync-server.sh` builds `native-cli` into `~/.local/share/codexbar-plasmoid/bin/codexbar-plasmoid` and installs the unit. The shipped unit pointed at a path no installer created, so `codexbar-sync-server.service` exited `203/EXEC` in a restart loop and every widget showed `ECONNREFUSED` on the sync port
- Scan Codex cost natively in the bundled Rust binary instead of the upstream CLI, which segfaults walking Codex history on Linux; one upstream `codexbar cost --provider codex` attempt remains as fallback when the native scan is missing or fails, and a cost failure still surfaces as `costError` without dropping usage
- Scan cost in a detached worker instead of on the render path: a full Codex cost walk takes 60-120s, so the previous inline scan either blocked every refresh or was killed at the request timeout and reported as a cost error
- Stop caching a failed refresh for the whole usage or cost window; a transient failure now opens only a short cooldown, so a provider that recovers is picked up on the next refresh
- Keep the last good usage limits on screen with a soft "retrying" note when a refresh fails, instead of replacing live bars with a red error or a bare cost panel
- Fall back to Codex's `oauth` source when the `cli` app-server bridge times out or the selected source is unsupported
- Reset the failure cooldown after a successful refresh so a recovered provider is not held back by an old backoff

## 0.1.9 — 2026-09-12

### Features

- Show a time-remaining marker on each popup usage bar so you can see at a glance whether the budget outlasts the window
- Add a "Pace to reset" tray bar tint (white / yellow / red) driven by CodexBar's per-window pace report
- Surface CodexBar's pace summary in the usage bar tooltip, computing one locally for windows the CLI does not pace
- Popup usage bars use the pace palette too when the tray tint is set to pace, so both views agree
- Split popup bars at the pace indicator with rounded ends; add position, bar, provider, and theme colors plus a narrow gaps-only mode in Appearance settings
- Show CodexBar's extra scoped rate windows (e.g. Claude's per-model weekly limit) as additional usage bars
- Add ClinePass support with API-key setup and 5-hour, weekly, and monthly quota bars

### Fixes

- Stop reporting pace for a window whose reset falls at or beyond its full length; there is no elapsed time to project from
- Translate the locally computed pace line instead of showing English text generated by the helper
- Hide the time-remaining marker when the reported reset is further away than the window length
- Give scoped rate windows (e.g. Claude's per-model weekly limit) their own row ids so they cannot shadow a standard window or inherit its pace
- Show scoped rate windows for native providers too; they were dropped for `usageRows` payloads
- Keep a manual cost refresh in the same shared cache slot as automatic polling, so its result is reused instead of landing in a refresh-only entry
- Render provider icons at the display's pixel density so they stay sharp on HiDPI screens

### Maintenance

- Keep one usage-bar palette shared by the tray and the popup, and one clock for every row

## 0.1.0 — 2026-07-12

Initial public release for Plasma 6.

### Features

- Compact tray representation with provider icons or multi-provider usage bars
- Full dashboard for usage limits, status, credits, costs, and recent history
- Per-provider source selection (`auto`, CLI/local, OAuth, API, web, Linux Helper, Native Auth)
- Optional multi-provider selection in the expanded view
- Automatic CodexBar CLI updates from GitHub releases (opt-in)
- Bundled Linux helper (`codexbar-plasmoid`) for Antigravity, Cursor, Devin, OpenCode, and OpenCode Go
- Email anonymization before data reaches QML (enabled by default)

### Requirements

- KDE Plasma 6
- Node.js on `PATH` (helper scripts)
- CodexBar CLI on `PATH`, or enable **Auto-download from GitHub** in widget settings
