1

Verdict pill. The row's answer in words: dry in 4d, tight, on pace. Container role = severity. 20 dp tall, 8 dp corners, label-small bold.

2

Value + unit + window. The percent is never alone: left is a title-small attached to the display-small number, and the window name sits directly under it.

3

Wavy indicator + clock notch. M3 Expressive's optional shape, 14 dp tall, active in the severity role, track in secondary-container. The 2 dp notch sits at (resetsAt − now) / (windowMinutes × 60000): fill left of it means burning too fast. The 4 dp end stop stays.

4

Sibling windows. The list that fixes "17 % of what?" — every other limit of the same provider, one thin 4 dp indicator each, tightest first.

5

Collapsed providers. Everything healthy is one line, one pill, one number. No bars where they would not change a decision.

Rules

the whole decision layer
Condition (all cached today)PillRole

otherwise on pace primary
provider.stale last good data secondary
provider.hasError refresh failed error

Severity drives color, everywhere

  1. ≥ 50 % → primary
  2. 20–49 % → tertiary
  3. < 20 % → error
  4. The notch and stop stay on-surface / primary so they never read as a second status.

Notch math, one line

WidgetPace.timeLeftFraction() already returns it. Draw it at left: fraction * 100%, 2 dp wide, 4 dp taller than the track.

Unknown (no reset, no window length, fraction > 1) draws no notch — never pin it to an edge.

What changes in the code

ordered by cost

Cheap — this week

  1. WidgetContent.kt: split LimitLine into a headline row and a WindowRow; render provider.rows instead of only row.
  2. Verdict: replace the free-form captionFor() string with a Verdict(text, role) from the table above.
  3. LimitBar: keep the 4 dp stop, drop the 24-cell quantisation for a weighted fill (LinearProgressIndicator semantics).
  4. Notch: reuse WidgetPace.timeLeftFraction, draw a 2 dp box on the track.

Expensive — needs RemoteViews work

  1. Wavy indicator: Glance has no canvas; a wavy drawable means either a generated bitmap clipped by width or a custom RemoteViews view. Ship flat first.
  2. Config: expose “show sibling windows” and “wavy / flat” in the widget settings, default on and flat.
  3. Sizes: one composable, three paddings — 4×4 full, 4×2 drops the window list, 2×2 keeps the headline only.

Palette tones are generated approximations of M3 roles, not Material Theme Builder output. Demo data: OpenCode Go monthly 17 % (dry in 4d), Claude weekly 28 %, CodeBuddy monthly 40 % — plus OC Go's 5h and weekly meters, which the current widget never renders.
