Tray redesign draft

The panel widget is doing a lot of work in about 70×32 pixels: several providers, one or two remaining-limit bars each, an optional metric, and a color that tries to mean both who and how empty. This page recreates the current tray, names what it actually encodes, then walks through a pile of redesigns — from cheap label tweaks to denser “chip” layouts. Nothing here is implemented.

What the tray can show

The compact face is assembled in QML from a small, already-normalized contract. Redesigns should reuse this rather than invent new fetches.

Bar groupsOne group per selected provider. 1–4 stacked lanes. Width default 18px.
Lane stylesfirst larger · equal · descending · last larger · alternating.
FillpercentLeft 0–100, exact width, 1px hairline if almost empty.
Credits fallbackIf a provider has no usage rows, it becomes a tinted pill with the number inside.
Metric textLowest remaining · session · weekly · credits · today cost. Default off. Shown only when the applet is wide enough and not vertical.
TintProvider hue · threshold white→yellow→red · theme text.
Icon modeMasked provider SVG, no bars.
ErrorReplaces the visual with data-warning.
LoadingBusyIndicator exists but is hardcoded visible: false.
ClickToggles the full dashboard. Tooltip is value · relativeTime.

What the current face gets wrong

1. Identity is gone

Three capsules, no icons, no letters. Threshold tint is a good remaining signal and a terrible “which provider?” signal. The orange thing reads as a status LED or a mute button, not “Codex weekly is 35%”.

2. Credits and remaining share a shape

A full remaining bar and a credits pill are both rounded rectangles. One encodes a fraction, the other a currency. On an 18px slot the credits number often does not fit, so you get an anonymous gray lozenge — then a second 6.5 beside it.

3. The metric has no unit

6.5 could be credits, dollars, or a percent with a dropped sign. compactValue() already knows how to print 35% or $6.5 — the credits path just stringifies one decimal.

4. Two stacked bars look like signal, not windows

Session vs weekly is the most useful pair in the product, but in 18×22px they become a Wi‑Fi glyph. bars-first making the top lane fatter is an arbitrary emphasis, not a legend.

5. Primary metric ≠ bar set

Bars can be all providers. The number is always the primary entry. So you can stare at Grok’s yellow stack while the 6.5 belongs to OpenRouter. That mismatch is the screenshot.

6. Status, stale, loading are missing

Expanded view has a status badge. Compact does not. The spinner is wired off. Stale only desaturates bar chrome. Outages and “Antigravity not running” never reach the panel.

Constraints to design against

Hard

  • Typical panel 28–44px tall. Vertical panels ~36–48px wide.
  • Width is rented from the whole tray. Every extra 20px is a political act.
  • Must follow Kirigami theme (no hardcoded dark-only chrome on the real widget).
  • 1–N providers, 0–4 limits each, plus credits-only vendors.
  • Click already means “open dashboard”. Don’t steal it for cycle-provider unless we add a modifier or a split hit target.

Design rules that hold up at 32px

  • One job at a glance: “am I about to get rate-limited?” beats “pretty equalizer”.
  • Name the thing that is red. Color without identity is an alarm with no source.
  • One encoding per channel. Hue = who or how-empty, not both. Use fill for remaining; use a pip or icon for identity; use a unit for the number.
  • Feature the worst. Healthy 88% can recede. 12% should shout.
  • Credits are not a bar. They are a quantity. Treat them as type, not fill.

Interaction ideas (the pixels are only half of it)

Tooltip is the cheap dashboard

Today: 6.5 · now. Spend the tooltip.

  • Codex weekly 35% · resets 4d 20h
  • Grok session 72% · weekly 88%
  • OpenRouter 6.5 cr
  • Updated just now

Plasma tooltips can be rich (we already import PlasmaComponents). This unblocks a quieter face.

Hit targets

  • Click empty chrome → expand (keep).
  • Click a group / pip → expand and select that provider in the switcher.
  • Wheel over the widget → cycle primary / compact metric. Optional, off by default.
  • Middle-click → refresh. Matches a lot of tray applets.

Density presets, not 6 combo boxes

Tray settings currently expose metric × show-text × display × which-providers × tint × width. Users pick combinations that fight each other (threshold tint + no labels + metric on the wrong entry).

  • Quiet — icon / ring, tooltip does the work
  • Alert — worst-first, pips for the rest
  • All limits — today’s labeled bar groups
  • Advanced stays, but collapsed.

Motion, used once

  • Do not animate fill on every 30s poll.
  • Do pulse the critical pip when a limit crosses 15%.
  • Crossfade stale → fresh so a refresh doesn’t flicker the tray.
  • Turn the existing BusyIndicator on for the first load only.

What I would actually try first

Not a vote for one true tray. A sequence that improves the screenshot without throwing away the bar language people already configured.

Ship soon — keep the bars, stop lying

  • #3 Unit + caption on the metric (6.5 cr, 35%, whose entry).
  • #20 Credits as type, never an unlabeled lozenge.
  • #1 Letter ticks or 12px icons on each group.
  • #18 Split encodings: provider fill, heat only as a stroke under 40%.
  • Tooltip rewrite to a per-provider remaining list.
  • Turn loading / stale / status into real compact states. The spinner is already in the tree.

Next — a named “Alert” mode

Concept #6 + #16 + #19. Default for people with many providers. Quiet while everything is healthy; worst remaining + pips when something dips. Does not replace All-limits, sits beside it as a density preset.

When we touch layout code anyway

Concept #5 fused chip so the widget reads as one applet, vertical column for docks, and middle-click refresh / click-group to select. Ring-on-icon (#9) is the icon-mode upgrade if someone still wants a 24px-wide tray.

Things I would not do

  • More unlabeled bar-weight styles. Five is already too many if none of them carry a legend.
  • Threshold tint as the default without identity. It photographs well and teaches the wrong lesson.
  • Putting today-cost and remaining in the same number slot without a unit.
  • Animating the equalizer on every poll.
  • Trying to show 4 lanes × 6 providers at 18px. That is a dashboard. Use pips.
